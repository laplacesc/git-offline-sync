# 界面规范

正式界面使用 React、HeroUI 3 与原生 Tauri 窗口。以生产组件为唯一交互实现，不再维护独立 HTML 原型。

## 外观

采用 GitHub 风格的浅色和深色主题：纯色背景、清晰边框、蓝色链接与焦点、绿色主要操作。危险操作保留红色，成功、警告与错误均有文字说明。

| 元素 | 浅色 | 深色 |
|---|---|---|
| 主背景 | 白色 | 接近黑色的中性背景 |
| 次级背景 | 浅灰色 | 深灰色 |
| 文字 | 深灰黑 | 浅灰白 |
| 分隔与控件边框 | 浅灰 | 中深灰 |
| 链接、焦点及选中信息 | 蓝色 | 亮蓝色 |
| 主要操作 | 绿色 | 绿色 |

支持浅色、深色、跟随系统，记忆用户选择。初始 HTML 与 React 挂载后的颜色保持一致，避免启动闪色。移除着色器、背景噪点、渐变和玻璃模糊；按钮不使用缩放动效。

应用标志始终为白底黑色图形。使用系统字体；等宽字体随包分发，无需联网加载。

## 窗口与布局

- 内容铺满窗口，不添加外层卡片、外边距或环绕阴影。
- 首次打开为 900×600；以后恢复历史窗口状态。macOS 顶部保留原生窗口控制与拖拽区域。
- 内网两个页签：导出更新 / 导入回传；外网两个页签：同步更新 / 回传提交。
- 项目从顶栏切换，配置在弹窗编辑；选项、管理与日志默认收起。
- 回传包按时间排序，每页 20 项，支持搜索及待接收 / 已接收 / 全部筛选；选中项与详情相邻展示。列表和待检查分支有各自的滚动区域。
- 日志使用原生按钮调节高度；长文件名和路径不能撑出窗口。

## 交互与验证

交互控件使用 HeroUI 原生组件，保留键盘导航、焦点反馈与语义标签。变更操作遵守运行器的忙碌、确认、取消与结果反馈规则；主题不改变同步行为。

验证至少覆盖浅色和深色的 900×600、1280×800，以及 560px 宽度下的内容溢出回归。检查主流程、回传列表、项目表单、设置、确认框和日志。主题测试覆盖持久化、系统主题变化与存储不可用时的回退。
