# 布局重设计后的原生验证（2026-10-20）

验证对象：当前 v2.1.9 工作区，包括新的侧栏布局及已有未提交功能。此次使用真实 macOS Tauri/WKWebView、独立应用配置和本地裸远程，未使用日常项目执行同步或推送。

## 发现与修复

1. 原生应用的默认和最小宽度均为 900px，原布局将 900px 归入窄屏，启动时隐藏项目和任务导航。将 JavaScript 和 CSS 的窄屏断点统一调整到 800px。实际 900×600 窗口中，侧栏和主区同时可见，内外网各三个任务页均无页面横向溢出；新增最小窗口回归测试。
2. 工作仓库缺少增量回传包依赖的主线提交时，原来仅显示 Git 底层错误。现在保留原错误，并增加在工作仓库执行 `git fetch origin` 后重试的说明。导入仍不自动 fetch、不切换分支；新增真实 Git 测试验证失败不改变引用及 HEAD，fetch 后可成功导入。
