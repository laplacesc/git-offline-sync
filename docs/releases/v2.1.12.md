# v2.1.12

重建同步工作区界面，将外网镜像导入与开发仓库同步拆开，改进两端包列表、分支管理和状态刷新。

## 界面与操作

- 前端迁移到本地 shadcn/ui 组件，统一侧栏、表单、弹窗、按钮及浅色、深色、跟随系统主题；字体和图标离线可用。
- macOS 内容延伸至窗口顶部，保留原生红黄绿按钮；Windows 保留自绘窗口控制。
- 分支管理并入内网“导入回传”和外网“回传提交”，支持行内新建分支、worktree、身份设置、Rebase、删除及内网推送。
- 分支列表改用固定表头和分层信息，未提交修改显示在关联分支行；统一输入框字体和提示浮层的垂直对齐。
- 精简重复成功提示，读取错误和同步状态保留在所属区块；日志与通知统一使用新的基础组件。

## 同步与刷新

- 外网“导入更新”只导入镜像仓库，“同步开发仓库”单独从镜像克隆或获取引用，保留本地分支、暂存区及未提交内容。
- 两端包列表默认显示最新 5 个，展开后每页 20 个，搜索覆盖全部包；对应区块的标题和操作位置保持一致。
- 保存 Git 设置后刷新工作区，切换开发仓库时只读取该仓库状态；普通刷新保留搜索、展开状态和表单输入。
- 完善组合读取的加载状态、并发请求去重及配置切换隔离，窗口再次失焦时取消待执行的焦点刷新。
- 增加真实 Git 回归测试，验证镜像导入不会改动开发仓库，显式同步也不会改动本地工作分支和未提交内容。

## 文档与清理

- 清理旧设计、原型、截图、重复文档及无调用代码，README 只保留当前版本必要说明。
- 技术栈与开发约定集中维护在 AGENTS.md，包校验、引用事务、推送确认、取消和冲突恢复仍由 Rust 核心负责。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`，内置 WebView2。
- Windows 已有 WebView2：选择体积较小的 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
- 最低 Git 版本为 **2.36**。
