# v2.1.16

修复分支列表中没有附加信息时分支名未垂直居中的问题。

## 修复

- 分支没有 worktree、当前分支或未提交修改标记时，隐藏空的元信息容器，使分支名与复制按钮在行内垂直居中。
- 有附加信息时保留原有两行布局及状态标记。

## 验证

- 浏览器布局验证覆盖无附加信息、worktree、当前分支和未提交修改四种情况。
- 自动化和浏览器验证不替代 Windows/macOS 原生应用交互验收。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`，内置 WebView2。
- Windows 已有 WebView2：选择体积较小的 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
- 最低 Git 版本为 **2.36**。
