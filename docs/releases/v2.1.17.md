# v2.1.17

加固离线回传、Patch 恢复和推送确认，并精简同步工作区。

## 修复

- 校验 Bundle/Patch 与开发仓库、镜像及历史提交的项目身份，拒绝错项目回传包。
- 拒绝 legacy receipt 的重复或冲突目标映射，避免推送到错误分支。
- 在 linked worktree 的 Patch 操作开始前取得专属锁，锁冲突时保持 HEAD、refs、配置、工作树和恢复日志不变。
- 修复标题和角色文字无法触发窗口拖动的问题，同时保留工具栏按钮交互。
- 保留未提交修改保护、冲突继续/中止、重复导入和推送 lease 校验。
- 清理无产品入口的旧同步 API、冗余返回值和未使用 UI 组件。

## 验证

- 207 项前端测试、15 项发布测试和 108 项 Rust 测试通过。
- TypeScript/Vite 构建、版本检查、Rust fmt、clippy 和差异检查通过。
- 已在隔离临时仓库和本地 bare remote 完成 macOS 原生 Tauri 流程验收。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`。
- Windows 已有 WebView2：选择 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
- 最低 Git 版本为 **2.36**。
