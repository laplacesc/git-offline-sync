# v2.1.19

减少分支操作后的重复刷新和回传导出的 Git 调用，修复批量基准配置读取的边界问题，并改善字体缩放与列表显示。

## 响应速度

- 新建分支、设置提交身份、Rebase、推送、删除分支及冲突继续/中止后，只刷新当前工作仓库，避免重复扫描传输目录、镜像及其他开发仓库。手动刷新、窗口回到前台、导入和导出仍执行所需的完整刷新。
- Bundle 回传一次读取所有分支的基准配置，减少逐分支重复调用 Git。
- Patch 回传一次批量检查提交变更，替代逐提交启动 Git；仍拒绝合并提交及空提交，保留冻结快照和发布校验。
- 本机隔离调试基准中，80 提交 Patch 的 Git 调用从 98 次降至 17 次，中位耗时从 1397 ms 降至 306 ms；40 分支 Bundle 从 133 次降至 55 次，中位耗时从 1823.5 ms 降至 793 ms。这些结果仅代表同机测试数据，不作为生产环境或 Windows 性能保证。

## 修复与显示调整

- 批量读取 `syncBase` 时，正确处理重复配置、空值、空白值、多行值及不带等号的配置项，保持与逐项读取一致，避免已清空的旧基准继续写入回传清单。
- 字号使用相对单位，辅助信息最小默认字号调整为 12 px；文本控件随字体增大，工具栏按空间换行，减少放大文字后的裁切。
- 配置名称和提交用户名与其他输入框使用相同的字体及字号。
- 包列表序号列随内容扩展，避免较长序号与包名重叠；展开 Patch 选项时单独占行，窄布局中的更新包操作区正确换行。
- “已导入”等状态与操作按钮垂直对齐，分页统计样式正确应用。

## 清理

- 移除日志面板不可达的关闭状态分支、未使用的样式和未配置使用的生成图标。
- 精简过时的迁移说明和模板注释，保留技术栈、安全边界和历史发布记录。
- 未新增依赖，保留包校验、仓库身份、引用事务、推送确认与 lease、锁、取消、恢复和未提交修改保护。

## 验证

- 210 项前端测试、15 项发布脚本测试、111 项 Rust 测试通过；生产构建、版本检查、Rust fmt、Clippy 和差异检查通过。
- 已完成当前工作树的全仓库审查及一轮无新增可证实问题的完整复查，最终源码指纹与验证对象一致。
- 已使用 macOS 隔离配置和本地仓库检查列表、字体、日志及分支操作；增加了 Patch 导入后树等价和批量配置语义回归。
- 未进行 Windows 原生交互/DPI、生产 GitLab 认证与真实推送、生产网络盘或正式安装包安装验收。

## 安装包

- Windows 首次离线安装：选择 `with-webview2.exe`。
- Windows 已有 WebView2：选择 `no-webview2.exe`，亦用于应用内更新。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
- 最低 Git 版本为 **2.36**。
