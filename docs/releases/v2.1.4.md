# v2.1.4

修复配置表单和同步页面中输入框字体、字号不一致的问题。

## 界面修复

- 配置名称、提交用户名和提交邮箱使用与包名前缀、分支、路径一致的等宽字体。
- 统一补丁选项中的新分支、独立工作树目录，以及分支搜索、回传包搜索的输入字体。
- 修复全局样式覆盖字号的问题，让文本输入框、路径输入框和基准分支选择框统一使用 JetBrains Mono 字体及 13px 字号，在浅色和深色主题下保持一致。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`。
- Windows 已有 WebView2：选择 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
