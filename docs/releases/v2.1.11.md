# v2.1.11

清理无调用代码和依赖，减少分支状态查询中的重复复制，保持现有同步与回传流程。

## 代码精简

- 移除无调用的前端接口封装及对应 Tauri 命令注册，保留核心同步流程使用的实现。
- 清理未挂载的版本组件、未使用的动画 Hook、分支表模式、可选参数、图标及配套样式。
- 删除两项未使用的字体依赖，以及原型中无用字段和已被覆盖的样式声明。
- 分支状态查询复用已缓存的统计结果，避免为每个分支复制整张统计表；同时移除导出清单中多余的引用列表复制。

## 测试与构建

- 限定前端测试发现范围，避免重复收集嵌套 worktree 中的测试，并限制并行数以减少资源竞争导致的超时。
- 更新测试夹具，继续覆盖请求去重、分支选择、冻结推送计划及更新安装重试。
- 移除 Windows 构建中仅打印参数的诊断步骤，保留发布脚本中的参数转发回归测试。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`，内置 WebView2。
- Windows 已有 WebView2：选择体积较小的 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
- 最低 Git 版本仍为 **2.36**。
