# v2.1.2

## GitHub 风格主题

- 浅色使用白色画布和浅灰次级背景，深色使用 GitHub 风格的深灰黑背景。
- 统一灰色边框、蓝色链接与焦点、绿色主要操作；保留浅色 / 深色 / 跟随系统及用户偏好记忆。
- 去掉 WebGL 着色器、背景噪点、渐变、玻璃模糊、大阴影与按钮缩放动效。
- 保留全窗口布局、HeroUI 原生控件、首次 900×600 尺寸及窗口状态恢复。

## 代码清理

- 删除旧背景渲染器、自定义动效模块、四步骤流程组件和旧侧栏版本组件。
- 清理对应的无用样式、过时测试及未使用的 Calistoga / Inter 字体依赖。
- 删除两套已被正式应用替代的 HTML 原型和旧截图，统一维护当前界面规范。

## 文件锁诊断

- 修复所有加锁失败都被提示为“可能有另一个同步实例”的误报。
- 区分真实锁占用和底层 I/O 错误，显示系统返回的具体原因及错误码。
- 识别远程桌面 `tsclient` 重定向路径，提供内网本地导出后复制包与清单的说明。

RDP 共享目录的锁兼容性仍需在现场验证，发布包继续要求成功加锁。若 `tsclient` 仍报错，可先导出到内网本地传输目录，完成后复制到外网共享目录；不要删除锁文件或同步状态来绕过错误。

继续兼容现有配置和 format 1 包协议。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`。
- Windows 已有 WebView2：选择 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
