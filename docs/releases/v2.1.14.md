# v2.1.14

将传输目录扫描与内外网端的本地分支刷新分开，避免远程传输目录读取缓慢时阻塞本地分支操作。

## 修复

- 传输目录与分支列表分别提供“刷新传输目录”和“刷新分支”，各自显示加载状态。
- 更新包和回传包扫描不再占用全局操作状态；目录读取缓慢或失败时，仍可选择、新建、整理和刷新本地分支，内网推送继续遵循原有校验及确认。
- 新建、删除、Rebase、推送及同步开发仓库完成后，仅刷新仓库状态，不再重新扫描传输目录。
- 导入更新或回传完成后，本地状态和导入结果先行更新，不等待传输目录重新扫描。
- 保留窗口返回前台时的独立刷新、旧请求结果隔离和同步记录异常时的操作限制。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`，内置 WebView2。
- Windows 已有 WebView2：选择体积较小的 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
- 最低 Git 版本为 **2.36**。
