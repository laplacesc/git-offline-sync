# v2.1.6

修复离线同步和回传审查中的边界问题，统一操作反馈，并让应用内更新说明与发布页保持一致。

## 同步与回传修复

- 改变分支基准时，如果已记录的旧基准引用丢失，会明确停止并提示恢复该引用，避免把旧发布线的提交混入新基准。
- 修复上游移动或重建同名 tag 后，外网开发仓库反复同步失败的问题。tag 按镜像更新，本地分支和未提交修改保持不变。
- 应用 Patch 前校验包类型、格式、仓库身份和未完成导出标记；错误项目或未完成的包会在修改仓库前被拒绝。仍支持没有 manifest 的手工补丁。
- 回传接收中断、审查工作树尚未建立时，先恢复工作树，再选择其他基准，避免忽略用户选择的整理目标。

## 操作反馈

- 读取、刷新、保存、同步、日志复制和版本检查统一使用顶部浮动提示，减少重复文字与页面跳动。
- 成功提示 5 秒后收起，悬停或聚焦时暂停计时；警告和错误可手动关闭，弹窗打开后仍可阅读和操作提示。
- 隐藏页签不再弹出状态提示，切换页签时清理对应提示；表单内容和分支选择仍会保留。

## 更新说明

- 修复应用内更新说明只显示版本号的问题。发布页与更新清单现在使用同一份完整 release notes。
- 发布时检查版本说明是否缺失、为空或与已有清单不一致，防止再次上传占位内容。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`，内置 WebView2。
- Windows 已有 WebView2：选择体积较小的 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
