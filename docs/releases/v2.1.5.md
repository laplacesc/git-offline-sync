# v2.1.5

本次更新优化 macOS 顶栏布局，并调整更新包区域的说明文案。

- macOS 标题栏与应用首行合并为 52px 高的单行顶栏，保留原生红黄绿按钮并与首行对齐。
- 顶栏标题及空白区域支持拖动窗口，项目菜单与设置按钮可正常操作。
- 将“包详情与其他更新包”更名为“更新包详情与选择”，方便识别包信息查看及手动选择入口。

## 安装包

- macOS：下载 Universal `.dmg`，支持 Apple Silicon 与 Intel。
- Windows 离线安装：下载 `with-webview2.exe`，内置 WebView2。
- Windows 已有 WebView2：可下载体积更小的 `no-webview2.exe`。
