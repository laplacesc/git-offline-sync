# v2.1.13

修复 v2.1.12 在安装包构建阶段被 Tauri 依赖版本检查拦截的问题，并包含该版本的同步工作区更新。v2.1.12 未生成正式安装包。

## 发布修复

- 将前端 `@tauri-apps/plugin-process` 固定为 2.3.1，与 Rust `tauri-plugin-process` 保持一致，修复 Windows 和 macOS 安装包构建失败。
- 保留依赖版本校验、更新签名及发布产物校验。

## 同步工作区更新

- 前端迁移到本地 shadcn/ui，统一侧栏、表单、弹窗、通知和主题，字体及图标离线可用。macOS 保留原生红黄绿按钮，Windows 保留自绘窗口控制。
- 分支管理并入内网“导入回传”和外网“回传提交”，未提交修改显示在关联分支行；统一输入框字体和提示浮层对齐。
- 外网“导入更新”只更新镜像，“同步开发仓库”单独克隆或获取引用，保留本地工作分支、暂存区及未提交内容。
- 两端包列表默认显示最新 5 个，展开后每页 20 个，搜索覆盖全部包。
- 修正保存 Git 设置、切换开发仓库及窗口焦点变化时的刷新，普通刷新保留搜索、展开状态和表单输入。
- 增加真实 Git 数据保护回归测试，清理旧设计与重复文档，精简 README。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`，内置 WebView2。
- Windows 已有 WebView2：选择体积较小的 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
- 最低 Git 版本为 **2.36**。

完整变更：https://github.com/laplacesc/git-offline-sync/compare/v2.1.11...v2.1.13
