# v2.1.15

修复同步、导出和冲突恢复中的五项问题，并进一步分离本地状态刷新与传输目录扫描。

## 修复

- 同步开发仓库时忽略自定义 fetch 映射，防止本地工作分支被覆盖；保留本地独有提交、暂存区和未提交内容。
- Bundle 发布前核对实际引用与清单快照，回传排除基线固定为提交 OID。导出期间引用变化导致校验不一致时，拒绝发布且不推进序号。
- 导入更新时在核心层校验包清单、已确认的镜像序号与分支/标签快照，并冻结本次导入内容。全量跳号必须明确确认；包或镜像状态变化后需刷新并重新确认。
- Merge 冲突解决并暂存后，“继续”会实际完成合并；未解决的冲突保持失败状态。
- Patch 导出范围含空提交时提前拒绝并提示使用 Bundle，避免生成无法通过现有继续流程接收的包。合并提交仍需使用 Bundle。
- 窗口回到前台时仅刷新本地状态，不自动扫描传输目录；分支刷新只读取对应仓库。同步状态刷新期间仍可搜索、展开和翻页浏览已有包，实际导入继续受状态校验约束。

## 验证

- 新增 12 项 Rust 安全回归测试，覆盖自定义 fetch 映射、并发导出、确认失效、包路径替换、Merge 继续与空提交 Patch。
- 本地通过 102 项 Rust 测试、192 项前端测试和 15 项发布脚本测试，以及生产构建、版本一致性、Rust 格式与 Clippy 检查。
- 自动化和模拟 IPC 验证不替代 Windows/macOS 原生应用交互验收。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`，内置 WebView2。
- Windows 已有 WebView2：选择体积较小的 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
- 最低 Git 版本为 **2.36**。
