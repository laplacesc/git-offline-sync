# v2.1.3

基于 v2.1.1，保留其主题和同步行为，仅调整 Windows 窗口标题栏。v2.1.2 的 GitHub 主题与清理改动已整体回退。

## Windows 标题栏

- 隐藏系统标题栏，将最小化、最大化 / 还原、关闭按钮整合到应用顶栏。
- 顶栏采用与应用一致的深浅外观，关闭按钮悬停时显示红色；窗口按钮不使用位移或缩放动效。
- 顶栏空白处、应用名称与标志可发起原生窗口拖动，双击通过 Tauri 切换最大化；交互控件不触发拖动。
- 最大化 / 还原按钮随窗口尺寸事件更新状态；关闭通过正常 CloseRequested 流程，继续保存窗口状态。
- 打开设置、项目编辑或确认弹窗时，窗口按钮仍可操作。
- Windows 专属配置保留 900×600 默认和最小尺寸，以及原生缩放、最大化、最小化和阴影设置。

macOS 保留原生红黄绿按钮及现有拖拽区域。

## 验证边界

已验证前端布局、窗口命令调用、弹窗层级、监听清理，以及 Windows 配置和权限。浏览器检查不能代替 Windows 实机验收；边缘缩放、拖动贴靠及不同 DPI 下的系统行为仍需实机复验。

最大化按钮为应用控件，当前未适配悬停时弹出的原生 Windows 11 贴靠布局菜单。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`。
- Windows 已有 WebView2：选择 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
