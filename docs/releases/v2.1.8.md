# v2.1.8

内网回传改为在现有工作仓库中处理，补齐 Patch 接收与分支删除的安全保护，并统一 HeroUI 组件和深浅主题。

## 内网回传与 Patch

- 内网导入 Bundle 和 Patch 不再新建 worktree，在已配置的工作仓库中切换分支并处理；有未提交修改、未跟踪文件或未完成操作时会先停止。
- 多分支回传按顺序整理，遇到冲突停止；重复导入复用原接收记录和审查分支。
- Patch 按内容保存接收记录，同包复制或改名后再次导入也不会重复应用；冲突继续完成后保存接收状态，收尾写入失败可重试。
- 外部执行 `git am --quit` 或跳过部分补丁后，不会将整组补丁误标为已接收。无法确认完成时保留恢复记录和待处理状态。
- 空目录或无效 Patch 条目只影响该包，列表显示具体错误并禁用导入，其他包仍可正常处理。
- Patch 导出冻结基准和提交范围；范围含合并提交时提示改用 Bundle，避免遗漏合并内容。

## 仓库与更新安全

- 删除分支保留提交旧值校验，并通过 Git 引用事务锁住现有工作树的 HEAD 后复查占用，防止并发切换分支造成悬空 HEAD。
- 补充分支在 bisect、rebase 期间的删除保护，兼容普通引用存储与 reftable；取消删除时释放已准备事务的锁。
- 支持按 Bundle 对象格式初始化 SHA-1 或 SHA-256 镜像，包括没有 manifest 的手工 Bundle。
- 正确保留工作树路径中的中文、空格、制表符和换行；未被忽略的未跟踪文件也会触发修改保护。
- 应用更新安装成功但重启失败时，只重试重启，避免重复安装报错。

## 界面

- 深浅主题采用中性灰配色，移除 WebGL、渐变、噪点和毛玻璃背景。
- 日期、提交时间和日志时间统一使用 HeroUI 只读组件；保留秒级日志时间，时间字段不进入键盘 Tab 顺序。
- 分页、空状态、配置错误摘要、表单分组、代码文本和提交差异刻度条统一使用 HeroUI 对应组件。

## 运行要求与安装包

- 最低 Git 版本为 **2.36**，用于无损读取工作树路径。
- Windows 离线首次安装：选择 `with-webview2.exe`，内置 WebView2。
- Windows 已有 WebView2：选择体积较小的 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
