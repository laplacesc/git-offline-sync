# v2.1.18

修复 macOS 手动切换主题后无法恢复跟随系统的问题，优化日志与分支列表，并重写使用说明、补充原生应用截图。

## 修复

- macOS 从手动深色或浅色切回“跟随系统”时，解除原生窗口的主题覆盖，立即恢复系统外观。
- 系统主题随后变化时，应用内容和标题栏继续同步；手动选择的主题保持固定。

## 优化与清理

- 将 Git 日志订阅与状态放到独立面板中，避免每条命令输出触发整个工作区重新渲染；收起记录期间仍持续收集日志。
- 分支列表使用集合查询已选项和未提交修改状态，减少逐行重复遍历，并保留搜索、范围选择和隐藏选项的选择状态。
- 删除不再被使用的输入方式监听、动效变量和日志主题变量。

## 文档

- 重写 README，补充安装包选择、两端配置、包与清单复制、全量跳号导入、回传及恢复说明。
- 添加当前源码运行的 macOS 原生应用截图，展示内网浅色、外网深色和应用设置。

## 验证

- 前端测试、发布脚本测试、TypeScript/Vite 生产构建和版本一致性检查通过。
- Rust fmt、clippy 和测试通过。
- 已在隔离示例仓库完成 macOS 原生镜像建立、导出、导入、开发仓库同步、日志和分支选择验收。
- 原生主题验收覆盖系统浅色与深色、手动主题切回系统、系统主题实时变化，以及手动主题保持固定。
- 未执行 Windows 原生交互验收、生产 GitLab 推送或大仓库性能基准。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`。
- Windows 已有 WebView2：选择 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
- 最低 Git 版本为 **2.36**。
