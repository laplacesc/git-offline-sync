# v2.1.1

## 回传包管理

- 内网「导入回传」采用紧凑列表与选中包详情布局，只显示一个导入入口。
- 每页显示 20 个包，支持按文件名、分支或序号搜索，以及待接收 / 已接收 / 全部筛选。
- 列表按时间和序号从新到旧排列；接收后自动展示下一项，仍需手动确认导入。
- 回传包和待检查分支使用独立滚动区域，改善大量包、长文本和小窗口下的使用体验。

## 窗口状态

- 首次启动使用当前最小尺寸 900 × 600。
- 关闭前保存窗口大小、位置、最大化和全屏状态；再次启动优先恢复历史状态。
- 移除启动时强制限制为屏幕可用区域 90% 的逻辑，仅在窗口真正超出当前可用区域时缩小适配。

## Windows 图标

- 修复安装程序和卸载程序仍显示 NSIS 默认图标的问题。
- 主程序、安装程序和卸载程序均使用与界面 logo 一致的白底黑色图形，覆盖带 WebView2 与精简两种安装包。

继续兼容现有同步配置和 format 1 包协议。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`。
- Windows 已有 WebView2：选择 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
