# v2.1.10

精简内外网同步工作区，统一分支管理与回传列表，支持直接接收本地分支和重复导入回传。

## 工作区布局

- 左侧直接列出同步配置，显示名称、内外网角色及仓库；点击即可切换，新建和编辑使用图标入口。
- 外网“同步更新”和“回传提交”合并为一个页面；内网“导出更新”和“导入回传”合并为一个页面。
- 页面内容居中并限制最大宽度，避免随窗口无限拉伸；调整窄窗口布局、搜索统计对齐和 worktree 路径选择。
- 分支管理和操作记录集中在左下角，仅显示图标，保留悬停提示和键盘操作。

## 分支管理与回传

- 内外网共用分支管理弹窗，支持创建分支、独立 worktree、写入提交身份、Rebase 和删除本地分支。
- 分支操作改为行内图标，新增推送入口；外网端禁用推送，内网端核对冻结的目标及提交计划后确认推送。
- 回传提交采用与分支管理一致的表格，展示分支、提交、基准和相对差异，不显示操作列；回传格式移至表格上方，Bundle 多选、Patch 单选。
- 删除更新包选择器及附属展示，自动匹配传输目录中的可用更新；较新全量包跳号同步仍需核对引用影响并确认。
- 内网导入回传改为单列列表，支持搜索、分页及行内导入，移除导入状态筛选和状态标记，支持再次导入同一回传。

## 回传接收保护

- Bundle 优先导入为外网原分支名，同名本地分支可快进时更新，分叉时使用带导入序号的备用分支并提示实际名称。
- 导入不自动切换分支、创建 worktree 或执行 Rebase；本地分支、收件引用和接收记录通过同一引用事务保存。
- 保留工作树占用、未完成操作和并发切换保护；重复导入复用接收记录，避免覆盖后续本地提交和基准设置。
- 缺少回传包依赖的主线提交时，提示在工作仓库执行 `git fetch origin` 后重试。
- 继续兼容旧版审查分支的接收记录和推送目标映射。

## 安装包

- Windows 离线首次安装：选择 `with-webview2.exe`，内置 WebView2。
- Windows 已有 WebView2：选择体积较小的 `no-webview2.exe`。
- macOS Intel / Apple Silicon：选择 `universal.dmg`。
- 最低 Git 版本仍为 **2.36**。
