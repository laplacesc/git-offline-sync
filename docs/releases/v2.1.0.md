# v2.1.0

## 界面与操作

- 使用铺满窗口的双页签界面：内网「导出更新 / 导入回传」，外网「同步更新 / 回传提交」。配置、选项、分支管理和日志按需展开。
- 交互控件统一使用 HeroUI 原生组件，改善键盘操作、焦点恢复、长文本换行及窄窗口布局。
- 支持浅色 WebGL 渐变、深色玻璃效果以及跟随系统；减少动态效果和 WebGL 不可用时提供静态回退。
- 界面 logo 与 Windows/macOS 应用图标统一为白底黑色图形。

## 同步与恢复

- 外网一次操作完成镜像导入及开发仓库更新或首次克隆，根据实际引用判断同步状态。
- Bundle 回传在独立工作树中整理，持久记录接收与审查状态；同包换路径或再次导入可复用已有审查。
- 推送确认绑定提交、目标引用、最终远程地址和远程旧值；执行前重新核对，执行后验证远程结果。
- 改善冲突继续、取消、导出恢复和重复回传处理，已核实推送的当前提交不再重复列为待办。

继续兼容现有 format 1 包协议；format 2 和 Patch 统一接收模型不包含在本版本中。

## 安装包

- **Windows 离线首次安装**：下载名称含 `with-webview2.exe` 的安装包，内含 WebView2 安装程序。
- **Windows 已有 WebView2**：下载较小的 `no-webview2.exe` 安装包。
- **macOS Intel / Apple Silicon**：下载 `universal.dmg`。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于自动更新。
