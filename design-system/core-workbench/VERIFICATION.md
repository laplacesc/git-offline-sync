# 精简版原型验证

验证对象：[交互原型](./index.html)。此记录替代上一版多页面工作台的验证结果。全部操作使用模拟数据，未执行 Git。

| 检查 | 结果 |
|---|---|
| 单窗口、两个页签、演示控制默认收起 | 通过 |
| 内网一键导出，无中间确认 | 通过；无变化不新建包，强制全量使用新序号 |
| 外网一次点击导入并更新开发仓库 | 通过 |
| 镜像导入后停止，再完成剩余同步 | 通过；已完成效果保留 |
| 回传自动接收和整理，中断后继续 | 通过；不重复接收 |
| 回传直接导出，Patch 单分支限制 | 通过 |
| 推送保留一次确认，提交变化后旧计划失效 | 通过 |
| 缺包改用全量、冲突处理、原包恢复、远程结果核验 | 通过 |
| 记录损坏、同号内容冲突 | 阻止相关操作，不显示默认同步位置 |
| 390px 下四个常用页签、七类场景、整理结果与推送对话框 | 无整页横向溢出 |
| 对话框焦点、Escape 返回、方向键切换页签 | 通过 |

## 外观验证

| 检查 | 结果 |
|---|---|
| 浅色、深色、跟随系统 | 默认系统；手动选择立即生效，刷新保留 |
| 系统深色切换为浅色 | 无刷新切换；显式浅色不随系统改为深色 |
| 深色玻璃、弹窗和输入控件 | 中性透明材质；桌面 60px、窄屏 40px 模糊，180% 饱和度，方向性阴影 |
| 浅色着色器 | 真实 WebGL 绘制，单个画布；抽样绘制次数符合限帧上限 |
| 深色和离屏停止、返回恢复 | 通过；观察实际 drawArrays 调用次数 |
| 页面隐藏和恢复 | 通过 visibilitychange 与 hidden 状态注入验证；浏览器自动化未形成真实隐藏标签页 |
| 减少动态效果 | 注入对应媒体查询结果；恰好绘制 1 帧，requestAnimationFrame 调用为 0 |
| WebGL 不可用 | 注入空上下文；静态渐变保留、无动画请求，模拟导出仍成功 |
| WebGL 上下文丢失和恢复 | 通过 WEBGL_lose_context 扩展触发；丢失时回退，恢复后重新绘制 |
| DPR 为 3 的桌面和 390px 窄屏 | 实际渲染像素比分别为 1.5 和 1 |
| 390px 外观菜单和设置弹窗 | 无横向溢出；Escape 关闭并返回焦点，外部点击关闭菜单 |
| 浅色主按钮文字对比度 | 白字与 #7351E5，约 5.20:1 |

另检查桌面截图、按钮可访问名称、JavaScript 语法、本地资源与文档链接。该验证仅覆盖原型交互，不替代后端集成测试或完整无障碍审计。
