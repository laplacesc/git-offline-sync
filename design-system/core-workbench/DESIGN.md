# 精简同步界面

[打开原型](./index.html)。此版替代之前的多页面工作台设计。

目标：配置一次，日常打开工具后直接同步。正常状态不要求用户学习镜像、快照、审查条目或操作计划。

## 一个窗口，两个页签

顶部只放项目选择、当前环境、外观和设置。项目角色在配置时确定；原型底部的环境切换只用于演示。

| 环境 | 页签 | 默认操作 |
|---|---|---|
| 内网 | 导出更新 | 拉取最新代码，自动生成全量或增量包 |
| 内网 | 导入回传 | 接收回传并自动整理，完成后检查并推送 |
| 外网 | 同步更新 | 导入更新，并为已配置的开发仓库获取引用 |
| 外网 | 回传提交 | 勾选分支，导出回传包 |

当前传输目录显示一行，可直接更改。主区域显示本次包或分支，底部只留最近一次结果和“查看记录”。

## 常用路径

- **内网带出去**：点击“导出更新”。自动拉取、比较、选包类型、校验并保存。无变化时只提示“没有新的更新”，不分配新序号。
- **外网拿到更新**：点击“同步更新”。先导入镜像，再为开发仓库获取引用；不切换或重写用户的工作分支。
- **外网带回来**：勾选分支，点击“导出回传”。Bundle 为默认格式，不再弹一次无必要的导出确认。
- **内网收到回传**：点击“导入回传”。自动接收并在独立工作树整理；在同一页显示可推送分支。点击“检查并推送”，核对提交后确认一次。

组合操作仍分阶段保存结果。取消或中断后，从未完成步骤继续。例如镜像已导入、开发仓库未更新时，按钮显示“完成同步”；回传已接收、整理未完成时，显示“继续整理”。

## 删除的内容

- 侧栏、待办首页、收件箱、审查中心、独立操作记录页。
- 推荐下一步、同步位置统计、进度链路、环境介绍、重复的成功横幅。
- 常驻校验清单、项目 ID、快照 ID、完整 SHA 和协议字段。
- 正常路径中的中间确认：生成计划、准备工作树、确认整理、确认导出。
- 常驻全局命令日志。

## 按需显示的内容

| 内容 | 入口 |
|---|---|
| 强制全量 | 导出卡片里的“选项” |
| 包文件、同步范围和开发仓库 | 更新卡片里的“详情” |
| 回传的分支和基准 | 回传卡片里的“内容” |
| Patch | 回传页的格式菜单 |
| 完整提交标识 | 推送确认中的“技术详情” |
| 命令日志 | “查看记录”中的单条日志 |
| 仓库路径 | 项目设置中的折叠项 |

## 只在需要处理时提示

提示使用“一句原因 + 一个动作”，不附带长篇原理说明。

| 情况 | 展示 |
|---|---|
| 缺包 | “缺少更新 #13，请补齐或改用全量包。”＋使用全量包 |
| 回传冲突 | 对应分支显示“有冲突”＋处理 |
| 导出中断 | “上次导出未完成。”＋继续导出 |
| 推送结果未知 | 对应分支显示“结果待确认”＋检查结果 |
| 记录损坏 | “无法读取同步记录，请检查后重试。”＋查看原因 |
| 同号内容冲突 | “包内容与已有记录不一致，请重新复制。”＋查看详情 |
| 推送确认后提交变化 | “提交已变化，请重新检查。”；旧确认按钮禁用 |

无须由用户判断的校验自动执行。失败时才展示原因；技术详情可展开。

## 保留的确认与核心约束

- 向 GitLab 推送前，展示目标、分支和提交，保留一次确认。完整 OID 收起，但后端计划仍固定提交。
- 全量包跨过缺失更新时，用简短确认说明目标版本；需要删除或回退的引用应在正式实现中直接列出，不依赖用户主动展开。
- 中止整理前，说明将恢复整理前分支；原回传保留。
- 非快进推送不能静默开启，正式实现应单独提示实际覆盖影响。
- 不因界面合并动作而跳过摘要、身份、依赖、旧值校验或恢复记录。
- 取消保留已完成步骤。远程结果不明时先查询，不直接重推。
- 已导出只表示文件生成；不推断对端收到或合入主线。正常页无需反复提醒未知状态。

## 外观

右上角外观菜单提供浅色、深色、跟随系统，默认跟随系统。偏好独立保存，刷新、切换演示环境或重置场景后保留；系统外观变化即时生效，手动选择时不受影响。主题在加载样式前恢复。

- **深色 · 夜航玻璃拟态**：深墨背景与三处柔光，无色玻璃面板使用 6% 白色、60px 模糊和 180% 饱和度；窄屏模糊降为 40px。包含顶部内高光、底部内暗缘、外阴影及 2.5% SVG 噪点。香槟金用于主操作和当前页签，状态通过文字说明。
- **浅色 · 着色器渐变**：按浅色要求调整参考中的深底配色，以暖白、浅桃、鼠尾草绿呈现真实 WebGL fbm 域扭曲背景；白色内容面板保证可读性，紫罗兰色作为操作强调色。主按钮略加深至 `#7351E5`，与白字对比度约 5.20:1。
- **绘制预算**：单个装饰性画布，桌面像素比最高 1.5、窄屏最高 1，绘制频率最高 24fps。深色模式不启动动画；离屏、页面隐藏和离开页面时停止，返回后恢复。减少动态效果时只绘制静帧，尺寸变化时重新绘制。
- **回退**：WebGL 不可用或上下文丢失时显示 CSS 静态渐变；上下文恢复后重新初始化。背景资源全部本地加载，失败不影响同步操作。

## 正式应用

本轮已将上述窗口、页签与主题接入正式 React/Tauri 应用，组合操作通过真实后端命令执行。Bundle 回传使用持久接收记录和独立工作树，推送通过冻结计划确认；实现范围及桌面实测见 [实现与验证记录](../../docs/implementation-verification.md)。新包协议及 Patch 统一接收仍按后续阶段推进。

## 原型范围

原型使用模拟数据，无需安装，直接打开 HTML 即可。底部“原型演示”默认收起，可切换环境和异常场景。首次配置、路径选择使用演示输入，不访问本地仓库。

正式接入时，后端提供一个组合操作入口及逐步结果；前端显示当前动作、一个停止按钮和最终结果。该入口按原有 [核心逻辑](../../docs/core-logic-redesign.md)执行各阶段，不新增一套同步规则。

原型默认 1000px 窗口，窄屏顺序排列。页签支持方向键、Home/End，对话框支持 Escape 和焦点返回。
